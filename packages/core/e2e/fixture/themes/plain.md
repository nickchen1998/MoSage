# Plain

A minimal theme used only by the e2e fixture project.

## When to use

Anything the test suite needs to render deterministically. It exists to prove
the themes gallery, the theme detail page, and the document back-link work —
not to look good.

## Page setup

A4 portrait, 76px margin, one measured column. Nothing bleeds to the sheet
edge and nothing is centred except the cover title.

## Color

Ink on paper: near-black text on white, one blue accent, hairline rules. Every
distinction survives a grayscale printer.

## Typography

One system family throughout. Hierarchy comes from size and weight, never from
a second typeface.
